# Create: Better Schematics

An addon for Create that fixes schematic configuration copying and adds selective Schematicannon building. Saved files remain ordinary Create `.nbt` schematics. NeoForge 1.21.1 is the main build, with Forge and Fabric 1.20.1 companions for supported Create 6 transfers. The addon configuration matrix covers 31 mod IDs; see [COMPATIBILITY.md](COMPATIBILITY.md) for its tested versions and limits.

[Source](https://github.com/IWasCool/create-better-schematics) · [Report an issue](https://github.com/IWasCool/create-better-schematics/issues) · [Compatibility details](COMPATIBILITY.md)

Version 0.0.10 changes the materials button to **Send materials to EMI** whenever EMI is installed. This requires [EMI: Create Schematics](https://modrinth.com/mod/emi-create-schematics) 1.1.0 or newer by **LiukRast and swzo**. The button passes Create clipboard entries to that installed addon's own exporter; its code manages EMI favourites and quantity display. Better Schematics does not bundle the addon or implement an alternative EMI exporter. Without it, the button stays disabled and its tooltip explains the requirement, including when JEI is also installed. Apply refreshes an EMI list exported from this cannon during the current session through the same addon. After reconnecting or changing schematics, click + again.

Version 0.0.9 automatically refreshes an imported JEI build list when you apply block skips, including restoring materials when you unskip them. Required amounts appear on the bookmark icons without extra tooltip text. The cannon controls now leave even space around the footer divider, and the skip menu centres its slots and grey scrollbar inside one panel, with a grey search field.

Version 0.0.8 extends Create Aeronautics: Transmission & Linkage support to connected universal joints. Select both endpoints to copy an andesite or brass rod within the same world; connections follow schematic rotation and mirroring, and the cannon requires one rod per connection. Better Schematics also suppresses Transmission & Linkage's repeated recommendation to install Create Aeronautics: Toolgun. Hydraulic links between ships still need reconnecting after placement.

Version 0.0.7 adds a **Send materials to JEI** button to the NeoForge Schematicannon menu. With JEI 19.53 or newer installed on the client and EMI absent, click the + button beside Confirm to bookmark the required items and quantities. Applied skip choices are excluded, and the JEI bookmark sidebar opens automatically. In 0.0.9, applying skips automatically refreshes the imported build list; click + again when changing schematics. Unrelated personal bookmarks remain. Amounts appear on imported JEI bookmarks and are remembered per world/server. The server needs Better Schematics 0.0.7 for this feature, but does not need a recipe viewer. In 0.0.10, EMI takes priority and exclusively uses EMI: Create Schematics as described above.

Version 0.0.8 is also verified with JEI **19.70.0.460**. Better Schematics 0.0.5 and earlier do not include the materials button; replace the old addon jar and restart Minecraft to enable it.

Version 0.0.6 supports installing Better Schematics on your client while joining a Create server without it. Saving works locally without any Better Schematics packets. The cannon's extended skip picker appears only when the connected server supports it; otherwise Create's normal controls remain available. Installing the addon leaves Create's block-state IDs unchanged and adds no required structure-processor registry entry. If your server already runs 0.0.5 or earlier, update its addon and the participating clients together: those older builds changed belt states and required the cannon protocol.

Save and share schematics normally; no Schematic Porter button is needed. Files remain ordinary Create `.nbt` structures with optional compatibility metadata and native configuration fields. Both modern and legacy item encodings are included for supported Create 6 transfers between NeoForge 1.21.1 and Forge/Fabric 1.20.1. A recipient does not need Better Schematics to load compatible blocks or native settings. The matching companion still supplies additional import and placement fixes where stock Create needs them.

A client can save only the chunks, entities and settings its server sends it. Some addons keep configuration exclusively on the server; client-only installation cannot recover those fields. Both instances need Create and compatible versions of the blocks/addons used by the build. This is not a general downgrade of arbitrary Minecraft versions. Cross-loader fluid units and placement behavior that require an adapter still need the matching companion.

In the Schematicannon, open placement settings and click the skip button to choose block types to leave out. The picker uses a nine-column inventory grid with Minecraft slots and Create's schematic-table frame and icon buttons. Each slot shows a block and its count; hover for its name, ID, exact count, and build/skip status. Click a slot to toggle it: skipped types have a red tint and cross, and are excluded even when materials are available. Scroll through larger schematics, search by name/mod ID, or use the Skip all and Build all buttons. Arrow keys navigate the grid; Space or Enter toggles the focused slot. Apply saves the choices to that cannon, updates its material checklist, and resumes it if its current missing block is now skipped; Cancel discards edits. Choices survive world reloads and affect all block-state variants of the selected types. Previously placed or already launched blocks are unaffected. The original skip-missing-materials toggle is available inside the picker. Selections remain configured on that cannon until changed.

Copy Create `.nbt` files between the instances' `schematics` folders as usual. Same-version recipients can load the file with Create even when Better Schematics is absent. Native arm targets, threshold values, inversion, stack display, and named list-filter settings have been verified this way through placement and the Schematicannon. The source Minecraft version and item components are retained; extra compatibility fields can be ignored by Create.

When the matching companion is installed, Forge and Fabric imports adapt supported configuration in memory, including arm coordinates, legacy filter fields and Fabric fluid units. The shared file is not rewritten. Capture a fresh schematic after installing the update so fluid switches include their unit information. Older files without known units keep their recorded amounts; check fluid limits when transferring those between loaders. Only the Minecraft/Create versions listed in the compatibility notes are verified; the embedded format is preparation for future ports, not a guarantee for unimplemented versions.

Both installations still need the blocks and addon mods used by the build. Extended features that need Better Schematics placement code, such as transformed wire endpoints and gauge connections, may require Better Schematics on the recipient too. A schematic can embed configuration data, but cannot supply missing mod behavior. Missing addon wire entities are skipped by stock Create without preventing the remaining supported machines from being built.

- Mechanical arm destinations use a position format both versions can read. Missing destinations remain saved and are retried as their blocks become available. Arm selection modes, rotated destinations, and active target indices on reload are preserved.
- Threshold switches import older Create 0.5.1 percentage settings and convert them once the destination inventory/fluid capacity is available. Modern Create 6 amount settings take precedence. Thresholds, inversion, and stack display mode survive schematicannon placement.
- Legacy item stacks use Minecraft's and Create's data fixers to migrate NBT into components. List filters retain their entries, allow/deny mode, respect-data option, and nested item data. Create 6 attribute filters retain built-in predicates, inverted rules and all/any/deny mode. Exports include equivalent legacy item fields for filters, custom names, lore, damage, enchantments, and custom data.
- Factory Gauges retain all four panel slots, filters, target amounts/units, logistics frequencies, recipe addresses/output counts, crafting layouts (including empty slots and ingredient item data), promise expiry settings, and connections to other gauges and redstone links. Connections and panel slots follow rotations and mirrors. Redstone supports reconnect when the cannon places their gauges later. Restocker settings are copied; pending deliveries from the original factory are excluded.
- Create: Power Grid 0.6.2 wires copy through creative placement and the schematicannon. Electrical endpoints and solid-wire routes follow rotations and mirrors; copies receive their own junction identities. Wire materials appear on the cannon's checklist and are consumed during construction. Colors, item counts, and NeoForge hanging-wire sag survive the transfer through Forge. Older Forge files without a saved sag value import using the wire definition's default curve.
- Tom's Storage 2.4.2 level emitters retain their filters, thresholds, and comparison mode; basic inventory hoppers retain their filters. Profiles also include inventory cable connector channels and camouflage blocks. Power Grid energy meters retain their display-unit setting. Crafts & Additions 1.6.0 motor speed settings are verified through exported schematic files. These configuration checks run on NeoForge.
- Additional profiles preserve Railways materials/colors, Bits 'n' Bobs text and lever settings, Pipe Organs MIDI frequency filters and pipe pitch, Mobile Packages port options, Numismatics bank labels, Propulsion limits/colors, Radar scan parameters, Simulated sensors/nameplates/typewriter bindings, Submarine and High Seas settings, Warnautics sirens, and Gadgets & Gizmos camera/display/dock/controller settings. Existing addon safe-NBT writers continue to supply their native configuration.
- Create Aeronautics: Transmission & Linkage 0.2.8 damping bearings retain resistance. Hydraulic connection heads and both hinge-head variants retain stretch resistance, free mode, expected length, redstone length limits and return force; brass hinge heads also retain angle limits. Universal-joint rods within a single world copy when both endpoints are selected, with one rod required by the cannon. Hydraulic rod connections, giant/creative rod modes and ship/hinge sublevel identities require reconnecting after placement. The addon's normal hydraulic linking action reinitializes expected length and redstone length limits, so those values must be reapplied after reconnecting a hydraulic rod.
- Create: Connected dashboards retain text; pulse generators retain their instruction parameters and restart idle with fresh counters. Create: New Age energisers retain capacitor mode, including a workaround for 1.2.0's mismatched save/load field spelling. Enchantment Industry forgers retain their selected mode.
- Diesel Generators engines retain their upgrade selection. Installed silencers and turbochargers appear in the cannon's checklist and must be supplied and consumed. Unknown upgrade IDs invalidate the material requirement instead of producing an unpaid part.
- Mekanism machines retain redstone control, side IO, auto-ejection and transporter colors. Factory sorting and logistical-sorter ghost filters/modes are preserved. Side settings follow rotations and mirrors, with all 72 facing/rotation/mirror combinations checked against Mekanism's own side API.
- Applied Energistics 2 full-block inscribers, IO ports, interfaces and pattern providers retain their supported operating settings, priorities and interface ghost stock lists. Storage cells, encoded patterns, upgrades, buffered resources and network identities are excluded from these profiles.
- Storage Drawers standard drawers retain remembered item types, locks, display options and priorities, while stored counts start at zero. Sophisticated Storage barrels, chests and limited barrels retain memory filters, no-sort slots, sorting/display settings and lock options. Stored items, installed upgrades, expanded capacities and linked-storage identities are excluded. These new integrations are verified on NeoForge 1.21.1.
- Belt casings are saved in Create's native `Casing` block-entity NBT, without adding a block-state property. Old schematics containing the addon's former material property are migrated to native NBT when read or exported. Tools that discard block-entity NBT also discard its casing material; normal Create schematic saves retain it.
- Twisted encased chain drives and adjustable chain gearshifts have 150 regression cases covering all three connection axes, both perpendicular shaft axes, every horizontal rotation/mirror, creative placement, saved cannon projectiles and reloads. A block-state-only processor fixture also checks interleaved twisted chains after creative placement and completed cannon builds. These cases pass using Create 6.0.10's existing orientation behavior; no additional chain-orientation patch was needed for the tested layouts.

Install `build/libs/create_better_schematics-0.0.9.jar` on your NeoForge client for local saving; the server does not need this addon. The older-version companions are `forge/build/libs/create_better_schematics-forge-1.20.1-0.0.7.jar` and `fabric/build/libs/create_better_schematics-fabric-1.20.1-0.0.7.jar`. Install on the destination server for extended placement fixes, and on both client and server for the NeoForge cannon skip picker and JEI material export. Singleplayer includes its own local server and retains the full feature set. The Forge companion includes arm/threshold fixes, gauge copying, Power Grid wires, and shared configuration profiles. The Fabric companion supplies arm/threshold fixes and native belt export for Create Fabric 6.0.8.1; it requires Create Fabric and its normal dependencies. The expanded addon matrix is verified on NeoForge; sharing a profile does not certify a different loader/addon version.

Export a fresh schematic from the original build after installing the addon/companion. Include every connected gauge and redstone support that should be copied, together with their backing blocks. Connections outside the selected region are excluded. Vanilla gauge exports omit the original gauge coordinates, so older files without this addon's position metadata cannot reliably relocate their connections; fresh exports supply that information. Existing information already removed from a schematic cannot be reconstructed.

For Power Grid builds, include the wire entities, both connected blocks, and their backing blocks in the selection. Wires connected to blocks outside the selection are excluded. Install Power Grid on both instances when transferring electrical builds.

Both instances still need the mods/blocks used by the schematic. This is configuration compatibility, not a general downgrade of every Minecraft block, addon format, or data component. Addon-defined attribute rules, older pre-Create-6 attribute encodings, and components without an implemented legacy equivalent are outside the supported conversion scope.

Other addons can register their block entity configuration fields during common setup with `SchematicConfigurationRegistry.register(blockEntityTypeId, configurationKeys...)`. `registerClass` matches a block entity class and its subclasses; `registerBehaviour` supplements any SmartBlockEntity hosting that behaviour. Dotted paths select nested fields, and `Instructions.*.Value` selects a field from each compound in an ordered list. `registerPlacementDefaults` supplies placement-only values such as an idle instruction index. The registry copies only declared fields, preserves native safe data, and leaves input tags intact. Settings containing world coordinates or physical network identities need a placement adapter, as implemented for gauges and Power Grid wires.

The inventory-style filter contains display icons rather than transferable item slots. The server validates the player's current cannon menu, distance, schematic, and selected block types. Regression tests replay filter saves, submit invalid and stale choices, and change filters while a paid block is in flight, checking that real inventories and projectiles are conserved. Power Grid wire materials are checked and consumed as one complete budget: a single stack cannot satisfy multiple parts of a larger cost. Failed extraction cannot launch an unpaid wire. NeoForge and Forge tests require full payment for a 130-item wire and verify that repeated removal returns exactly those 130 items.

Validation runs real NeoForge and Forge game test servers. Gauge tests exchange actual exported files in both directions and check rotated/mirrored cannon projectiles, reloads, all four slots, redstone supports placed before gauges, partial selections, and all 144 combinations of mounting face, facing, rotation, and mirror. The committed fixtures are real exports from Create 6.0.10/NeoForge and Create 6.0.8/Forge. Existing tests also cover machine configuration, belt casings, block skip choices, material/fuel consumption, server menu validation, packets, and save/client synchronization.

The compatibility checks cover native shared files and historical converted files, rotated/mirrored arm targets placed before their depots, saved cannon projectiles, list and attribute filter behavior, named/styled items and lore, automatic Fabric fluid units, world reloads, and serialization without querying neighboring chunks. A separate Create-only test mod loads real exported files with Better Schematics completely absent. See the compatibility notes for results and the separate Create Fabric upstream baseline.

The 0.0.8 content-addon run passed 405 required tests, including the 35 existing transmission configuration checks, 19 new universal-joint rod checks and 150 chain-drive checks. The base run without optional addons passed 196 tests; the real client also verified suppression across four Toolgun-notice handler calls. The transfer matrix has 81 addon fixtures across 31 mod IDs using actual exported files, rotation/mirroring, saved cannon projectiles, and reloads. Working cannons verify installed-component costs, including one rod per copied joint connection. Seeded storage checks verify that profiles copy settings while real source inventories remain unchanged and copied storage stays empty. The earlier Forge Power Grid suite passed six tests; the new rod adapter is specific to NeoForge 1.21.1.

Build with Java 21:

```powershell
.\gradlew.bat build
.\gradlew.bat -p forge build
cd fabric
.\gradlew.bat build
```

Use Java 21 to run the Fabric Gradle wrapper (Gradle 8.14.3); its production code targets Java 17. All three builds resolve their dependencies from public Maven repositories. NeoForge pins Create 6.0.10; Forge targets Create 6.0.8 and Java 17. Gauge, wire, and configuration profile code is shared in `common/src/main/java`. Release JARs exclude test classes and fixtures. See [CHANGELOG.md](CHANGELOG.md) for release notes and upgrade requirements.
