# Changelog

## 1.0.0

- Public release for NeoForge 1.21.1, with Forge and Fabric 1.20.1 companions.
- Preserve supported machine configuration, filters, arm targets, belt casings and Factory Gauge connections in ordinary Create schematics.
- Add Schematic Table mod inspection and a searchable Schematicannon block picker with saved skip choices.
- Export material quantities to JEI, or use the separate EMI: Create Schematics addon when EMI is installed.
- Support selected addon configuration, Power Grid wires and same-world Transmission & Linkage universal-joint rods.
- Include compact optional table controls, native menu artwork and scrollbar, and the Creative Crate manual-pause fix.
